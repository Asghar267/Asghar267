## 🚀 Featured Projects

### 🧠 RV32I SoC with DOT4 Vector Accelerator: RTL to ASIC Implementation
A custom 32-bit RV32I RISC-V core integrated with a DOT4 INT8 / INT16 vector dot-product accelerator.
- **Synthesis:** Cadence Genus on TSMC 180nm, targeting 350 MHz
- **Timing closure:** worst negative slack improved from **-1.16 ns to 0.0 ps** using pipelining and SDC multicycle paths
- **Physical design:** floorplanning, placement, clock tree synthesis, routing and static timing analysis in Cadence Innovus
- **Verification:** core-level, accelerator-level (**208/208 pass**) and SoC-level (**16/16 pass**) simulation
- **Tech:** Verilog, SDC, Tcl, Cadence Genus, Cadence Innovus

### 🔬 DTMF Chip: Synthesis to GDSII
Took a DTMF chip design (RTL with macros) through synthesis and physical design to GDSII stream-out, with CDC constraints in place.
- **Tech:** Cadence Genus, Innovus, Tcl

### 🛠️ Open-Source RTL-to-GDSII Flow (in progress)
A 4-bit synchronous up/down counter with load and reset, taken through the full digital flow with Icarus Verilog, Yosys, OpenROAD, Magic and Netgen on the Sky130 PDK.

### 🗂️ Cache Memory Simulator (C++17)
A direct-mapped, 8-line, write-through cache simulator written with OOP and lambdas, with a full report and presentation.

### 🧮 Digital Design Labs
Multiplier architectures from Half Adder through Radix-4 Booth, a RISC-V branch/control-flow study, and a custom instruction datapath extension on RV32I.
